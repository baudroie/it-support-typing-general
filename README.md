# ITサポートたいぴんぐ 一般企業用

[アプリを開く](https://baudroie.github.io/it-support-typing-general/)

業務会話を使って日本語タイピングを練習する、企業研修向けのアプリです。CCNATigerのアカウントは不要です。

- 練習モード：分野・難易度を選び、時間制限なしで練習
- ランクモード：90秒のタイピングに挑戦
- 配布されたID・パスワードでログイン、またはゲストで開始
- ログインした利用者の結果のみ、専用の学習ログへ保存。ゲストの記録は保存しません

このリポジトリはGitHub Pagesへの配布用です。公開ファイルはReleasesの `site.zip` に格納し、チェックサムを確認してActionsから公開します。名簿・パスワード・学習記録・接続先スプレッドシートの情報は含みません。

タイピングのスコア・ランクは本アプリ独自の基準で、業務理解や判断力の評価ではありません。
